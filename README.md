# 奔虎锂电 · 车型电池智能匹配系统

## 功能
输入电动车车型 → 秒出可安装的奔虎磷酸铁锂电池
- 支持按车型查电池 / 按电池查车型两种模式
- 覆盖小牛、九号、极核、雅迪、台铃、绿源、新大洲、五羊本田、小刀等品牌
- 每条数据标注来源和可信度
- 支持 PWA，可添加到手机主屏幕

## 部署
部署于 Gitee Pages，访问链接见仓库 Pages 服务。

## 数据更新
- `vehicles.json` — 车型数据库
- `batteries.json` — 电池参数
- `generate_html.py` — 一键生成 HTML

更新流程：修改 JSON → 运行 `python generate_html.py` → 提交推送

## 奔虎锂电
磷酸铁锂(LFP)电池专家，为二轮电动车提供安全、长续航的电池方案
