# 奔虎锂电 · 产品展示与车型电池智能匹配系统

## 功能
一个页面包含两块：

**⚡ 产品展示**（仿公司展示站设计）
- 19 款奔虎磷酸铁锂电池产品卡片：产品图 / 参数图 / 规格书 / 认证报告
- **点击产品图片 → 弹出该电池可匹配的全部车型**
- 每款产品文字介绍下方有"点击图片查看匹配车型"提示
- 64V / 76.8V 系列筛选

**🔍 智能匹配**
- 输入车型 → 秒出可安装的奔虎锂电池（电压 / 尺寸 / 功率三重匹配）
- 输入电池型号 → 显示该电池适配的车型
- 覆盖小牛、九号、极核、雅迪、台铃、金箭、黑骑士、爱玛等品牌
- 每条数据标注来源和可信度
- 支持明暗主题、PWA，可添加到手机主屏幕

## 数据更新
- `vehicles.json` — 车型数据库（电池仓尺寸、电机功率、原厂电池规格）
- `batteries.json` — 电池参数表（电压、容量、尺寸、放电电流、适配电机）
- `generate_html.py` — 一键生成 index.html
- `page_template.html` — 页面模板（一般不用改）

更新流程：修改 JSON → 运行 `python generate_html.py` → 提交推送

### 新增电池产品
1. 在 `batteries.json` 的「电池列表」里加一条记录
2. 有产品图时：图片放进 `assets/img/`，规格书/认证报告放进 `assets/files/`
3. 在 `generate_html.py` 顶部 `ASSET_MAP` 里加一行：
   `("型号", "长×宽×高"): ("产品图路径", "参数图路径", "规格书路径", "认证报告路径")`
   （暂无图的电池会自动显示占位卡片，有图后补一行即可）
4. 运行 `python generate_html.py`
